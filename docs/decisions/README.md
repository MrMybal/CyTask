# Décisions d'architecture

Les ADR consignent un choix important, son contexte et ses conséquences. Le statut
`proposé` signifie que le choix structure le travail préparatoire mais peut encore
être remplacé avant l'implémentation concernée.

- [ADR-0001 — Monolithe modulaire et workers](ADR-0001-monolithe-modulaire.md)
- [ADR-0002 — Préparer la synchronisation sans répliquer la base](ADR-0002-preparation-synchronisation.md)
- [ADR-0003 — Pile de la première tranche](ADR-0003-pile-technique.md)

Les prochaines décisions à prendre sont la licence, la pile du client installé et
le format de distribution des plugins.
