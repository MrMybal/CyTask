Les dossiers organisent les tâches ; les vues présentent le même travail de plusieurs façons. Changer de vue ne duplique pas les tâches.

## Hiérarchie des dossiers {#folder-hierarchy}
Le contrôle d’ajout de la section dossiers crée un dossier racine. L’action d’ajout propre à un dossier crée un enfant. Utilisez le chevron pour développer ou replier ceux qui contiennent des sous-parties. Ajoutez une tâche dans le groupe voulu ou ouvrez d’abord sa liste.

La sélection d’un dossier limite le travail affiché. Si le nombre semble trop faible, vérifiez les filtres : certaines tâches peuvent être masquées par l’état ou le responsable choisi.

## Choisir une présentation {#pick-a-presentation}
| Vue | Utilisation |
| --- | --- |
| Liste | Titres et contexte descriptif |
| Compacte | Lignes denses et colonnes d’attributs modifiables |
| Kanban | Cartes regroupées par état |
| Canvas | Ressources disposées librement et réflexion visuelle |
| Graphe | Exploration des hiérarchies et relations |

## Trier et filtrer {#sort-and-filter}
Cliquez sur les en-têtes des colonnes qui prennent en charge le tri ; un nouveau clic change le sens. La barre d’outils filtre texte, états, priorités, personnes, dates et labels, et propose tri et vues enregistrées.

Une vue enregistrée conserve une présentation et ses filtres, pas un projet distinct. Réinitialisez les filtres pour retrouver l’ensemble du périmètre.

## Projets volumineux {#large-projects}
Les grandes listes sont paginées. Utilisez Afficher plus lorsque proposé. La sélection groupée vise les lignes indiquées par ses contrôles, pas automatiquement toutes les tâches masquées du projet.

Les cartes peuvent afficher des aperçus d’images jointes. Ouvrez la pièce jointe pour vérifier son contenu complet.
