Les plugins étendent projets et onglets de tâches sans imposer chaque fonction optionnelle au travail courant. Activez l’intégration dans la page Plugins du projet avant d’attendre ses contrôles.

## Familles d’intégrations {#available-integration-families}
- Git associe tâches, commits, branches et URL de dépôt. Il reste facultatif.
- AI Assistant gère les connexions aux fournisseurs et l’assistance contextualisée.
- Unreal apporte des données de tâche structurées pour le moteur et les assets.
- CyRevision relie révisions et tâches.
- CyAnnota propose l’annotation des images et vidéos compatibles.
- CyMD enrichit l’édition Markdown aux endroits intégrés.

Désactiver un plugin peut masquer ses contrôles sans supprimer la tâche concernée.

## Extensions des messages et textes {#message-and-text-extensions}
Les plugins pris en charge peuvent fournir cartes de contenu, actions sur ressources et onglets. Utilisez les contrôles dans le contexte du message, fichier ou document où ils sont proposés. Les aperçus restent soumis aux permissions du contenu.

CyAnnota passe par l’intégration embarquée dans les contextes Web et desktop ; sa disponibilité dépend du média et de sa configuration.

## Limites {#boundaries}
Le système utilise des capacités déclarées et des rendus pris en charge. Ce n’est pas une place de marché exécutant arbitrairement du JavaScript inconnu. Accès aux fournisseurs et exécutables locaux peuvent exiger une configuration administrateur.

Les références Git ne constituent pas un client Git complet. L’intégration Unreal ne garantit pas toutes les versions du moteur : testez la combinaison réellement utilisée par le projet. Relisez les recettes d’assets avant de les lancer.
