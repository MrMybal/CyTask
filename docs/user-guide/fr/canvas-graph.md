CyTask propose deux vues spatiales aux fonctions différentes. Le Canvas est un tableau libre ; le Graphe représente les relations structurées du projet.

## Créer un canvas {#create-a-canvas}
Créez une ressource Canvas dans le projet ou le dossier, ou ouvrez son salon. Ajoutez notes, texte, images, vidéos, formes et dessins avec les outils disponibles. Disposez les éléments puis enregistrez la ressource.

Déplacez-vous avec le panoramique et le zoom. Sélectionnez un élément avant de le modifier ou déplacer. Ne supprimez pas la ressource pour réinitialiser le cadrage : navigation et contenu sont distincts.

Le canvas convient aux briefs visuels, références et préparations. Ce n’est pas le service Miro et il ne nécessite aucun compte Miro. Seuls les outils exposés par CyTask sont disponibles.

## Explorer le graphe {#explore-the-graph}
Ouvrez Graphe depuis les contrôles de vue ou le salon correspondant. Les nœuds représentent la structure accessible : dossiers, tâches et sous-tâches. Les arêtes montrent hiérarchie et relations.

Zoomez, déplacez et recentrez pour retrouver un groupe. Ouvrez un nœud de tâche pour consulter sa fiche. Modifiez réellement parent ou dépendance dans les contrôles de la tâche : une ligne décorative ne constitue pas une relation enregistrée.

## Grands tableaux {#work-with-large-boards}
Séparez les sujets dans plusieurs canvas. Filtrez le projet avant d’explorer un réseau dense. De grandes images ou vidéos consomment de la mémoire même affichées en petites cartes.

Un canvas conserve contenu et disposition ; le graphe dérive des données du projet. Ils ne constituent pas des sauvegardes interchangeables.
