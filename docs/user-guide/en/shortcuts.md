Keyboard controls speed up common actions. A shortcut can depend on the current screen and should not replace the visible controls when a text editor owns focus.

## Workspace shortcuts {#workspace-shortcuts}
| Key | Action |
| --- | --- |
| Ctrl + K | Open the command palette |
| / | Focus task search when not typing in a field |
| N | Start a new task in the task workspace |
| B | Show or hide the sidebar |
| Escape | Close the active overlay or cancel its current interaction |
| F1 in desktop | Open the bundled user guide |

Use Tab and Shift + Tab to move through controls, Enter to activate and Space for checkboxes. Status and assignee controls can be used without dragging a card.

## Appearance {#appearance}
Choose an appearance preset in Settings and tools rather than relying on a browser’s forced dark-mode setting. CyTask offers several light and dark palettes, not just pure white and black.

If a menu looks inconsistent after an update, reload the current application build before changing project data. Browser zoom can help legibility without changing task content. The guide has its own light/dark reading control and print layout.

## Language {#language}
English is the default; French is available in the application, desktop selector and guide. Change the interface language with its selector. Preferences are stored in the current client context when storage is available.

Switching interface language does not translate project names, user messages or imported tasks. This guide’s captions and explanatory diagrams are translated; example workspace content remains as authored.

See [troubleshooting](doc:troubleshooting) if a control cannot be reached.
