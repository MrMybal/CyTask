Le clavier accélère les actions courantes. Un raccourci dépend parfois de l’écran ; il ne remplace pas les contrôles visibles lorsqu’un éditeur de texte possède le focus.

## Raccourcis de l’espace {#workspace-shortcuts}
| Touche | Action |
| --- | --- |
| Ctrl + K | Ouvrir la palette de commandes |
| / | Rechercher les tâches hors d’un champ de saisie |
| N | Créer une tâche dans l’espace de tâches |
| B | Afficher ou masquer la navigation latérale |
| Échap | Fermer le panneau actif ou annuler son interaction |
| F1 dans le desktop | Ouvrir le guide embarqué |

Tab et Maj + Tab déplacent le focus, Entrée active et Espace coche. État et responsables se modifient sans devoir glisser une carte.

## Apparence {#appearance}
Choisissez une palette dans Paramètres et outils plutôt que de forcer le mode sombre du navigateur. Plusieurs palettes claires et sombres sont disponibles, pas seulement du blanc et du noir purs.

Après une mise à jour, rechargez l’application si un menu semble incohérent, sans modifier les données. Le zoom du navigateur peut améliorer la lecture. Le guide propose six thèmes, une recherche globale dans l’en-tête et une mise en page d’impression. Ctrl+K ouvre sa fenêtre de recherche ; Échap ferme la recherche ou réduit une image agrandie.

## Langue {#language}
L’anglais est proposé par défaut ; le français est disponible dans l’application, le sélecteur desktop et le guide. Utilisez le sélecteur de langue. Le choix est mémorisé dans le contexte du client si le stockage est disponible.

Changer la langue ne traduit pas noms de projet, messages et tâches importées. Légendes et schémas du guide sont traduits ; le contenu exemple reste dans sa langue d’origine.

Voir [dépannage](doc:troubleshooting) en cas de contrôle inaccessible.
