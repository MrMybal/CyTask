Use folders to keep tasks navigable, and views to look at the same work in different ways. Switching a view does not duplicate tasks.

## Folder hierarchy {#folder-hierarchy}
Use the add control in the folder section to create a root folder. A folder’s own add action creates a child. Expand or collapse folders with children using their disclosure control. Create tasks from the relevant group or open its task list first.

Selecting a folder scopes the displayed work. Check active filters if the task count is lower than expected; a folder can contain tasks that the current state or assignee filter excludes.

## Pick a presentation {#pick-a-presentation}
| View | Best for |
| --- | --- |
| List | Titles and descriptive context |
| Compact | Dense rows with editable attribute columns |
| Kanban | Cards grouped by workflow state |
| Canvas | Spatial resources and visual thinking |

## Sort and filter {#sort-and-filter}
Use column headings to change supported sort order. Repeating a heading changes the direction. The toolbar offers filters for text, state, priority, people, dates and labels, plus sorting and saved views.

A saved view stores a useful combination of view and filters; it does not create a separate project. Reset filters when you need to return to the full working set.

## Large projects {#large-projects}
Long lists load in pages. Use Show more when it is offered. A bulk selection applies to the rows identified by the current selection controls, not automatically to every hidden task in the project.

Task cards can show uploaded image previews. A media preview is a convenience, not a substitute for opening the attachment and checking its full content.
