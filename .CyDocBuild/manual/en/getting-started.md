CyTask organizes projects, tasks, discussions and shared resources in one workspace. Choose the connection mode before creating your first project.

## Choose a mode {#choose-a-mode}
| Mode | Use it for | Where data lives |
| --- | --- | --- |
| Local solo | Personal work, without a hosted server | A folder selected in the desktop client |
| Local + Sync | Trusted devices sharing a local workspace | That folder, replicated by an external synchronization tool |
| Team server | Members with individual accounts and permissions | The server database and configured file storage |

A browser connects to a team server. The desktop client can connect to a server address or start its own local engine. Sync is not a replacement for server access control.

## Your first project {#your-first-project}
1. Open or create a workspace. For a team server, sign in with an account supplied by its administrator.
2. Create a project using the project rail. Projects appear like servers in the left navigation.
3. Open a task room, create a folder, then add a task with a clear title.
4. Set its status, assignees, priority and due date. Add a description or checklist.
5. Open Team chat to discuss the task, or copy its link into a message.

## Find your way {#find-your-way}
The project rail selects a project; the adjacent sidebar lists its rooms and categories. Inbox and My tasks help you follow your work across the available project context. Settings and tools contains administration and integrations.

Use the language selector to choose English or French. English is the default. Project titles, messages and descriptions remain as written by their authors.

The manual is bundled with Desktop. Press F1 to open it without starting a project server. To read a downloaded copy, extract the complete archive and open `Documentation/Documentation.html`; keep its `DocData` folder beside it. Search, images and diagrams work offline. This does not make a remote project available offline.

Continue with [desktop and local workspaces](doc:desktop-local) or [team server connection](doc:team-server).
