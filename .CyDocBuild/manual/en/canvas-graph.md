CyTask has two spatial views with different responsibilities. Canvas is a freeform board; Graph is a representation of structured project relationships.

## Create a canvas {#create-a-canvas}
Create a Canvas resource in the project or folder, or open the corresponding room. Add supported notes, text, images, videos, shapes and drawings using its tools. Arrange items spatially and save the resource after changes.

Use pan and zoom to move through the board. Select an item before editing or moving it. Avoid deleting a resource simply to reset the viewport; navigation and content are separate.

A canvas is useful for visual briefs, reference collections and planning. It is not the Miro service and does not require a Miro account. Only the tools exposed in CyTask are supported.

## Explore the graph {#explore-the-graph}
Open Graph from the project’s view controls or its graph room. Nodes represent the available project structure: folders, tasks and subtasks. Edges show hierarchy and task relations.

Zoom, pan and recenter to find a group. Open a task node to inspect its detail view. Change the actual parent or dependency in the task controls rather than treating a decorative line as a saved relation.

## Work with large boards {#work-with-large-boards}
Keep unrelated topics in separate canvases. Use project filters to reduce the task set before inspecting dense relationships. Large images and videos still require memory even when displayed as small cards.

A saved canvas stores its layout and content; Graph derives its information from project records. They are not interchangeable backups of each other.
