Chat rooms keep project discussion next to the work. Use a shared room for a topic, a restricted group for selected members, and task comments for decisions that should stay attached to one task.

## Start a conversation {#start-a-conversation}
Open the project’s chat room. Use its group creation action to name a discussion and select participants where offered. Check the membership before posting. A private group does not make its files public to the rest of the project.

Write in the composer, use formatting tools when needed and send. Mention a member with the mention picker to direct their attention; a mention is not an assignment.

## Share a task {#share-a-task}
Copy the task link from its detail view and paste it into a message. Supported CyTask links show a task preview. Clicking it opens the record if the reader has access. A link to another server still requires that server’s account.

Prefer a task link over a screenshot when status or assignees will change: the record remains the source of truth.

## Share media {#share-media}
Attach images, videos or files with the picker or drag and drop. Wait for upload completion before sending. Images have previews and can open enlarged with a download action. Supported videos play inside the chat and can also be opened or downloaded.

An unsupported codec may require downloading the original. A source URL is not the same as an uploaded attachment. Avoid posting very large media repeatedly when a resource link will do.

Use [notifications](doc:notifications) to understand unread indicators and [calls](doc:calls) for live communication.
