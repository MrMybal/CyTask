Use Inbox to review work that needs attention rather than repeatedly browsing every folder. My tasks narrows the view to assigned work; Today, Later and Completed offer other useful entry points.

## Follow activity {#follow-activity}
Open an inbox entry to inspect the task or discussion behind it. Read the current record before acting: a notification describes an event, not necessarily the latest status.

Task activity records changes and comments. Chat mentions direct attention to a message. Announcements provide a room for project news instead of mixing every update into task descriptions.

## Unread indicators {#unread-indicators}
Room and project unread indicators help identify new activity. Read markers are associated with the current client context; do not assume that every open device will have identical unread counts instantly.

Opening the relevant room updates its read state. An unread badge is not a deadline, an agent claim or proof that someone has acknowledged a request.

## What is not implied {#what-is-not-implied}
The presence of inbox and room indicators does not promise a configured email digest, mobile push delivery or operating-system notifications for every event. Keep critical deadlines in task attributes and establish a team convention for urgent escalation.

Agents use a separate durable call and notification workflow. Creating an ordinary task does not itself guarantee that an external AI has been called or has started work.
